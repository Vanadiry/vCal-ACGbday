# check online

## 生日数据检查

比较 `data/` 中每个角色的生日与外部数据源是否相同。  
可补全缺失的年份并写回数据文件。

如需跳过某个角色的联网检查，可以在角色数据中加入 `bday.verified: true`。

### 用法

```text
vcal check bday [--data DIR] [--report PATH] [--auth TOKEN]
```

| 参数 | 默认 | 说明 |
| --- |--- | --- |
| `--data` | `data` | 数据目录 |
| `--report` | `report/bday_report.yml` | 报告输出路径 |
| `--auth` | 匿名 | bangumi 访问令牌，用于拉取受限条目 |

执行 `vcal check bday` 时，会自动执行 `vcal check lint`，若不通过，将终止检查。  
建议手动指定需要检查的目录，因为默认全量检查，非常慢。

### 源状态

每个数据源有三种状态：

| 状态 | 含义 | 判定 | 提示 |
| --- | --- | --- | --- |
| 有数据 | 源返回了生日字段 | 参与判定 | - |
| 无数据 | 源存在但无生日字段 | 不参与 | 干净 |
| 404 | 源不存在 | 不参与，按无数据 | 提示 404，应删除该源 |

### 判定规则

月/日与年份分开检查，各自套用同一套规则。

#### 月/日（m/d）

**1 个有效源**：

| 情况 | 结果 |
| --- | --- |
| 源 == data | PASS |
| 源 != data | X（可能记录错误） |
| 无有效源，但 data 有数据 | X（需补充源） |

**2 个有效源**：

| 情况 | 结果 |
| --- | --- |
| 两源相同 + data 相同 | PASS |
| 两源相同 + data 不同 | X（可能记录错误） |
| 两源不同 + data == 其一 | ?（另一源可能有问题） |
| 两源不同 + 都与 data 不同 | X |

2 个源时，其中一个无数据或 404 时，按 1 个有效源的情况处理。

#### 年份（y）

data 缺年份时：

| 情况 | 处理 |
| --- | --- |
| 1 个有效源有年份 | ? 补全 |
| 2 源相同有年份 | ? 补全 |
| 2 源其一有年、另一无年数据，且日月一致 | ? 补全 |
| 2 源日月一致但年份不同 | ? |

#### 自动修正

仅两种情况下自动补全年份，并写回数据文件，其余只记录：

1. 单源（或双源相同）有年份，data 缺年份
2. 双源，其一有年记录，且日月一致，data 缺年份

### 结果

| 结果 | 含义 |
| --- | --- |
| Y | 通过 |
| ? | 新增 / 补全，或源疑似有问题 |
| X | 数据不符 / 没有源 / 源 404 |
