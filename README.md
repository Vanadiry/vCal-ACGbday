# vCal-ACGbday

这里记录了二次元作品中，角色的生日数据，并构建为 ics 和 js 以方便日历和浏览器使用。

二次元角色都是虚拟角色，所以只过生日，不长岁数（暴论）。  
总之角色的出场日期、年龄都忽略，只记录生日 XD。

更新日志/使用方法/角色列表/不同文件的说明，请参考 Vanadiry 网站上的 [vCal-ACGbday](https://vanadiry.com/wiki/vcal/acgbday/)。

## 使用

在日历中，使用下面的链接来订阅：  
`https://data.vanadiry.com/subscribe/vCal_ACGbday.ics`

vCal-ACGbday 还提供了防止剧透的 / 使用角色原名的订阅，请参考[订阅日历文件](https://vanadiry.com/wiki/vcal/acgbday/subscribe/#%E8%AE%A2%E9%98%85%E6%97%A5%E5%8E%86%E6%96%87%E4%BB%B6)小节。

订阅在 macOS 上的表现如下：
<img src="https://vanadiry.com/library/wiki/vcal/acgbday/vcal_acgbday_01.webp" height="300">

如需在你的网页嵌入，请参考[在网页上嵌入](https://vanadiry.com/wiki/vcal/acgbday/subscribe/#%E5%9C%A8%E7%BD%91%E9%A1%B5%E4%B8%8A%E5%B5%8C%E5%85%A5)小节。
